# Codeforces Solutions

[![Codeforces](https://img.shields.io/badge/Codeforces-shaniprajapati-1F8ACB?style=flat&logo=codeforces&logoColor=white)](https://codeforces.com/profile/shaniprajapati)
[![GitHub](https://img.shields.io/badge/GitHub-shaniprajapatiii-181717?style=flat&logo=github&logoColor=white)](https://github.com/shaniprajapatiii)


This repository contains only the solutions submitted **during live Codeforces contests**. Each folder represents a specific contest date, and only the problems solved within the contest time are included here.

All solutions are implemented in **Java**, focusing on clear logic, optimal time complexity, and real-time problem-solving under contest constraints.

---


## Contest Participation Approach

- Only solutions submitted **within the official contest duration** are included.
- Each contest folder contains the problems solved during that contest, named by the contest date.
- No upsolving or post-contest solutions are present in this repository.
